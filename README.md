# Anime Wallpaper Slider

A beautiful, responsive anime wallpaper slider built using HTML, CSS, and JavaScript. This project showcases smooth transitions and elegant UI elements for anime enthusiasts.

## 🚀 Live Demo
You can check out the live website here: 
👉 **[https://roshankumar161161.github.io/Anime-image-slider](https://roshankumar161161.github.io/Anime-image-slider)** 

---

## 🛠️ Features
* **Smooth Transitions:** Elegant sliding animations between wallpapers.
* **Responsive Design:** Works perfectly on desktops, tablets, and mobile devices.
* **Interactive UI:** Dynamic "See More" and navigation buttons (`<` and `>`).

---

## 📂 Project Structure
Ensure the following files are in your project root:
* `index.html` - The main structure of the website.
* `style.css` - Custom styling and animations.
* `script.js` - Slider functionality.
* `art1.jpg` to `art6.jpg` - High-quality anime wallpapers.
